# Frontend README

This is the frontend repository for **DiscordCloud**. It contains the client-side code responsible for the user interface and interaction.

## Technologies Used

- React.js (JavaScript library for building user interfaces)
- Next.js (React framework for server-side rendering, routing, and more)

## Setup Instructions

1. Clone this repository to your local machine.
2. Navigate to the project directory.
3. Install Node.js and npm if not already installed.
4. Install dependencies: `npm install`
5. Run the frontend server: `npm run dev`
6. The frontend development server should now be running locally.

## Usage

- This frontend interacts with the backend API to provide file upload, download, deletion, and listing functionalities.
- Access the application in your web browser at `http://{YOUR_LOCAL_IP_ADDRESS}:3000`.
